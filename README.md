## 操作説明

- ゲーム起動後はマウスデバイスのみ使用
- ゲーム内に表示される黄色い円の内側をドラッグすることで操作
- プレイシーンに限り、黄色い円内外のドラック操作が異なる
	- 内側 → 操作ボールの指定方向への加速
	- 外側 → カメラの視点操作
